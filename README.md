# Zomato-Style Monthly Food and Tiffin Expense Tracker

The **Zomato-Style Monthly Food and Tiffin Expense Tracker** is a desktop-based expense management application developed using **Python Tkinter, SQLite, and Matplotlib**. The application is designed to help users record, organize, monitor, and analyze their daily food and tiffin expenses through a simple and user-friendly graphical interface.

The system allows users to enter details such as the **date, food item, category, amount spent, payment method, and notes**. All expense records are securely stored in an **SQLite database**, allowing the data to remain available even after the application is closed.

The application provides a **dashboard** that displays important monthly information such as total expenditure, tiffin expenses, other food expenses, number of transactions, and the remaining monthly budget. Users can also view their complete **expense history**, search for specific transactions, edit existing records, and delete unwanted entries.

To make expense analysis easier, the application integrates **Matplotlib** to generate graphical representations of spending patterns. These include **category-wise spending charts and daily spending graphs**, helping users understand where their money is being spent and identify their major food-related expenses.

The application uses a **Zomato-inspired interface**, incorporating a food-oriented design and a clean navigation system while focusing specifically on personal expense management rather than food ordering.

### Technologies Used

* **Python** – Core programming language
* **Tkinter** – Graphical User Interface
* **SQLite** – Database management and persistent storage
* **Matplotlib** – Data visualization and analytics
* **VS Code** – Development environment

### Main Features

* Add food and tiffin expenses
* Categorize food expenses
* Record payment methods
* Store data using SQLite
* View complete expense history
* Search expenses
* Edit and delete transactions
* Set a monthly food budget
* View total monthly expenditure
* Track tiffin-specific spending
* Display budget utilization
* Generate spending charts and graphs
* User-friendly Zomato-inspired interface

The primary objective of this project is to provide a **simple, reliable, and visually informative solution for managing monthly food expenses**, while demonstrating the practical application of **GUI development, database management, CRUD operations, and data visualization in Python**.
